# Guy on Island
_Todo: Find a better name_

## Summary
This "game", originally made for the Fedijam 3, is not exactly a game. It's meant as a screensaver. It is inspired by the screensaver "Johnny Castaway", made by Sierra in 1992 (https://en.wikipedia.org/wiki/Johnny_Castaway). The main difference is: It has no predefined scenes. The "guy" decides what to do, based on needs he/she has.

The version submitted to FediJam 3 can be found [here](https://codeberg.org/Doubi/guy-on-island/releases/tag/fedijam).

## Current features
### Hunger
The guy has a "hunger" need, that decreases over time and can be replentished by eating fish.
### Fishing
The guy can go fishing at predefined fishing spots. After a random period of time, a dead fish appears behind the guy.
### Walk to random locations
The guy walks to a random location on the island and then says a random phrase from a predefined collection.
