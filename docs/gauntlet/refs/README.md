## Preflight obrigatorio

Antes de comecar qualquer ronda:
1. `curl` ou screenshot da barra para este directorio
2. Verificar que o ficheiro abre (nao esta corrompido)
3. Registar URL e data nesta tabela
4. Confirmar que o critico consegue abrir o ficheiro (caminho absoluto)

Se nao conseguires fazer fetch da barra: abortar a ronda, escolher outra barra.
