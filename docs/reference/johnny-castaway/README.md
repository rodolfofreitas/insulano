# Referencia Visual -- Johnny Castaway (Sierra, 1992)

Sprites originais do Johnny Castaway usados como REFERENCIA DE ESTILO E ANIMACOES.
Fonte: The Spriters Resource (https://www.spriters-resource.com/pc_computer/johnnycastaway/)
